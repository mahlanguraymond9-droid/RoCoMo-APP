# RoCoMo App

Mobile-first RoCoMo Pest and Hygiene Services web app.

Core workflow:
Customer → Quote → Approval → Job → Service Report → Invoice → Payment → Follow-up → Review

Included:
- Dashboard
- Customers
- Jobs and statuses
- Quotations with VAT/discount and printable quote
- Service reports
- Invoices & payment status
- Business reports
- Follow-ups
- Settings
- Local/offline storage
- JSON backup export
- Installable PWA structure

## Run
Open index.html in a browser. For full PWA/offline installation, serve the folder from HTTPS (for example GitHub Pages, Netlify or Vercel).
